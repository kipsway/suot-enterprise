# ОхранаТруда Про — подробный гайд запуска и эксплуатации

Версия: **2.3.0** · Платформа: Windows 10/11

---

## 1. Запуск приложения

### Вариант A — portable-сборка (рекомендуется пользователям)
1. Возьмите `dist\SUOT_Neo_portable.zip` или папку `dist\SUOT_Neo\`.
2. Распакуйте/скопируйте в удобное место: `D:\SUOT\`, рабочая папка, сетевой диск.
3. Запустите `SUOT_Neo.exe`.
4. В правой нижней части окна появится адрес локального API
   (`http://127.0.0.1:<порт>`). Данные хранятся **рядом с exe**
   (`data\`, `media\`, `backups\`) — переносимая папка = все данные.

### Вариант B — из исходников (разработка)
```bat
install.bat                          :: всё автоматически (venv + зависимые + запуск)
```
или вручную:
```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python desktop.py                    :: окно pywebview (WebView2) или системный браузер
```

## 2. Первый вход и первичная настройка

1. При первом запуске создаётся **владелец-администратор**: логин `admin`,
   пароль `admin`. **Сразу смените пароль**: Настройки → Аккаунт.
2. На экране языка выберите Русский или English — это выбор делается на каждом
   устройстве отдельно и запоминается для пользователя (ru/en + формат даты
   ДД.ММ.ГГГГ или ГГГГ-ММ-ДД в Настройки → Оформление → Дата).
3. Нажмите «Загрузить демо» в пустой таблице, чтобы увидеть примеры данных.

## 3. Оформление и темы

Настройки → Оформление:
- **Тема**: Тёмная, Светлая, Океан, Лаванда, Янтарь, **Авто** (следует за
  системной схемой Windows; переключение применяется на лету).
- Акцентный цвет, масштаб шрифта, плотность, скругление, «стекло».
- Пользовательский CSS и водяной знак для печати (ЧЕРНОВИК).

## 4. Пользователи и роли

Пользователи → «Пользователи» (внизу сайдбара), доступно только Администратору.

| Роль | Что может |
|---|---|
| **Администратор** | Всё; управление пользователями, журнал аудита, настройки |
| **Manager** | Полный рабочий доступ к модулям |
| **Инспектор** | Просмотр/создание/редактирование своих и выданных записей; без удаления |
| **Наблюдатель** | Только просмотр (чтение, без изменений и экспорта) |
| **Пользователь** | Только свои записи (изоляция по владельцу) |

В карточке пользователя: смена роли (выпадающее меню), блокировка/разблокировка,
сброс пароля. Блокировка мгновенно инвалидирует токены.

## 5. Диагностика системы

F1 → Справка → **Диагностика** (или кнопка в нижней части справки):

- Версии приложения, Python, лицензия;
- Статус сервера, время работы, потоков;
- WebView2 (Edge): установлен / нет, версия;
- База данных: путь, размер, целостность (integrity_check), число таблиц и записей;
- Диск: занято/свободно по каталогам;
- Журнал диагностики (последние события, с фильтром по уровню);
- Тулбар: обновить показатели, экспорт отчёта диагностики.

Наблюдателю диагностика доступна в режиме просмотра.

## 6. Резервное копирование

Настройки → Данные → Резервные копии:
- «Создать» — полный ZIP (БД + медиа/фото);
- «Авто» — расписание (ежедневно/еженедельно), ротация до 5 копий;
- Список копий: предпросмотр состава, скачивание, восстановление.
Копии лежат в `backups\` рядом с exe.

## 7. Сборка дистрибутивов

```bat
python scripts\build_exe.py        :: dist\SUOT_Neo\SUOT_Neo.exe
python scripts\smoke_test_exe.py   :: автопроверка собранного exe (health + ui)
python scripts\make_portable.py    :: dist\SUOT_Neo_portable.zip
iscc installer\suot_neo.iss        :: dist\SUOT_Neo_setup.exe (нужен Inno Setup 6)
```

Замечания по сборке:
- exe собирается PyInstaller (`suot_neo.spec`), self-contained (около 76 МБ).
- **Edge PDF**: сервер вызывает `msedge.exe --headless --print-to-pdf`; на
  машине должен быть установлен Microsoft Edge. Генерация ждёт появления PDF
  до 30 с (Edge не всегда сам завершает процесс — сервер делает kill).
- Inno Setup (ISCC.exe) не входит в репозиторий — устанавливается отдельно.

## 8. Тестирование

Серверные suite (FastAPI TestClient) и E2E (Playwright, headless Chromium):

```bat
for %t in (tests\test_*.py) do python %t     :: все server- и e2e-suite (~500+ проверок)
python tests\test_part2_e2e.py               :: полный E2E-флоу
python scripts\run_perf.py                   :: замер avg/p95 по ключевым GET-энподынтам
```

Что покрыто: все API-модули, изоляция по ролям, GDA (журнал аудита),
экспорт/импорт, печать/PDF, AI, плагины, миграция legacy-схемы Qt,
E2E-флоу интерфейса (диагностика, Наблюдатель, автотема, сессии).

## 9. Безопасность

- Пароли: PBKDF2 (100k итераций) + соль;
- Логин: rate-limit 5 попыток, фиксация неуспешных входов в журнале;
- Токены: HMAC-SHA256, TTL 30 дней (remember me) / 12 часов, с ревокацией;
- Изоляция данных: принадлежность записей по владельцу, роль-проверки на сервере.

## 10. Устранение неполадок

| Симптом | Решение |
|---|---|
| Окно не открылось / белый экран | Проверьте WebView2 (Edge); перезапустите `SUOT_Neo.exe` |
| PDF не создаётся | Проверьте наличие Microsoft Edge; просмотрите журнал диагностики |
| Порт занят | Сервер сам выбирает свободный порт; в настройках можно зафиксировать |
| Потеряли пароль admin | Владелец-админ: удалите `data\users`-файл → заново `admin/admin` (см. Вариант B) |
