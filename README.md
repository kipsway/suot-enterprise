# ОхранаТруда Про

Современная веб-система управления охраной труда: **FastAPI + pywebview +
Alpine.js**, полностью заменяет legacy-версию на PyQt5 и работает как
десктоп-приложение Windows.

```
Версия: 2.3.0 · Лицензия: внутренняя · Платформа: Windows 10/11
```

---

## Быстрый старт

> Подробнее: [`docs/RUN_GUIDE.md`](docs/RUN_GUIDE.md) — первый вход, роли,
> диагностика, бэкапы, сборка, устранение неполадок.

### Вариант A — готовый exe (рекомендуется)
1. Возьмите `SUOT_Neo_portable.zip` (или `dist\SUOT_Neo\`)
2. Распакуйте в любую папку → запустите `SUOT_Neo.exe`
3. Первый пользователь автоматически становится администратором
   (сид `admin/admin` — смените пароль в Настройки → Аккаунт!)

Данные (БД, фото, бэкапы) создаются **рядом с exe** — переносимая папка = все данные.

### Вариант B — из исходников
```bat
install.bat          :: python + venv + зависимости + запуск
```
или вручную:
```bat
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
python desktop.py    :: окно pywebview; без WebView2 — браузер
```

### Сборка exe / portable / установщик
```bat
python scripts\build_exe.py        :: dist\SUOT_Neo\
python scripts\make_portable.py    :: dist\SUOT_Neo_portable.zip
iscc installer\suot_neo.iss        :: dist\SUOT_Neo_setup.exe (Inno Setup 6)
python scripts\smoke_test_exe.py   :: автопроверка собранного exe
```

## Архитектура

| Слой | Технологии |
|---|---|
| UI | Alpine.js 3 (локальный vendor), vanilla JS-модули, CSS-переменные |
| API | FastAPI, JWT-подобные HMAC-токены, SSE-стриминг |
| Данные | SQLite (WAL) — по таблице на модуль; изоляция записей по `user_id` |
| Desktop | pywebview (Edge WebView2) → фолбэк в системный браузер |
| AI | Ollama или любой OpenAI-совместимый сервер |

```
desktop.py ── uvicorn(server/app.py) ── server/routers/* ── services/database.py
     │                                        │
     └── webview → web/index.html ←──────────┘  (static: web/, media/)
```

## Роли пользователей

| Роль | Доступ |
|---|---|
| **Администратор** | Все модули, пользователи, журнал, настройки |
| **Manager** | Полный рабочий доступ (кроме пользователей/журнала) |
| **Инспектор** | Работа с записями без удаления (свои + выданные) |
| **Наблюдатель** | Просмотр (без изменений и экспорта) |
| **Пользователь** | Только свои записи |

## Безопасность

- Пароли: PBKDF2 (100k итераций) + соль; rate-limit логина (5 попыток)
- Токены: HMAC-SHA256, TTL 30 дней (remember) / 12 часов
- Изоляция: каждый запрос фильтруется по владельцу; админ-операции помечены 403
- Блокировка пользователя мгновенно инвалидирует его токены
